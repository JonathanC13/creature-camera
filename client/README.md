# Creature Camera Website
ReactJS

# Function
Dashboard for two roles:
<br>
1. Admin
<ul>
  <li>Manage Users</li>
  <li>Manage Cameras</li>
  <li>Assign cameras to users</li>
  <li>View videos from assigned cameras</li>
</ul>

2. Client
<ul>
  <li>View videos from assigned cameras</li>
</ul>

# .env variables to set
VITE_BACKEND_BASE_URL = 'http://localhost:5000/'
<br>
VITE_BACKEND_API_URL = 'http://localhost:5000/api/v1/'

# To run
> npm run dev
